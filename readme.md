## About Project
This is a python project to clean and analyze hospital patient records using Pandas and Matplotlib. It removes duplicate data, fills missing age values, calculates how many days patients stayed, and makes a bar graph of their ages.

## What I Used
- Python 3
- Pandas (for data cleaning and calculation)
- Matplotlib (for the bar chart)

## How to run
1. Open terminal in the project folder.
2. Make sure pandas and matplotlib are installed (`pip install pandas matplotlib`).
3. Run the code by typing: `python one.py`
4. Enter your csv file name when it asks (like `patients.csv`).
5. Choose an option from the menu to see the output.
